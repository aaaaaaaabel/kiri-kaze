# Fossil Index

Fossil Index is a fossil catalog platform built with **Nuxt**, **Vue 3**, and **Firebase**.

The project explores how to build a scalable domain catalog system with modern frontend architecture and data-driven UI.

## Features

- Infinite scroll catalog
- Fossil taxonomy data structure
- Authentication system
- Data synchronization scripts
